Java Constructor – 20 Practice Questions

Basic Level
1. Create a Student class and print "Hello Student" using a default constructor.
2. Create a Student class and print the student's name using a constructor.
3. Create an Employee class and initialize id and name using a constructor.
4. Create a Car class and initialize brand and price using a constructor.
5. Create a Mobile class and initialize name, price, and RAM using a constructor.

6. Create a Rectangle class and calculate the area using length and breadth.
7. Create a Circle class and calculate the area using radius.
8. Create a BankAccount class and initialize account holder name and balance.
9. Create a Book class and initialize title, author, and price.
10. Create a Product class and calculate total price using quantity and price.
Constructor Overloading

12. Create a Student class with default and parameterized constructors.

Advanced Level
