# Java Modifiers

Types of Java Modifiers

**1. Access Modifiers**

		i. public: Accessible from anywhere.

		ii. private: Accessible only within the same class.

		iii. default: Accessible within the same package.

		iv. protected: Accessible within the same package and child classes.

**2. Non-Access Modifiers**

			i. final: Cannot be changed or modified.

			ii. static: Belongs to the class, not an object.

			iii. abstract: Used to create incomplete classes and methods.
